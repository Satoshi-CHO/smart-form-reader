# Smart Form Reader 📄🔍

*Read this in [English](README.md).*

**Smart Form Reader** は、スキャンされた帳票や書類の画像を効率的に分析し、指定した領域の文字（テキストや数字）を抽出するOCRデスクトップアプリケーションです。

このプロジェクトは、画像切り出し精度が高く構築されている一方で、**「将来より高精度なOCRエンジン（AIモデルやAPI等）が登場した際に、簡単にエンジンを差し替えられること」** を前提に、オブジェクト指向設計のベストプラクティス（SOLID原則やデザインパターン）に基づいて設計されています。  
そのため、**拡張性の高いOCRシステムのテンプレートや、Pythonを用いたアーキテクチャ設計・リファクタリングの学習用教材** としても活用いただけます。

---

## 🎯 主な特徴と設計意図

1. **拡張容易なアーキテクチャ (Strategy & Factory パターン)**  
   新しいOCRエンジン（例: 最新のAPI, PaddleOCR等）を追加したい場合、既存のコードをほとんど編集することなく、`IOcrStrategy` を実装した新しいクラスを1つ作り、Factoryに登録するだけで利用可能になります。（オープン・クローズドの原則）
2. **役割ごとの分離 (単一責任の原則)**  
   特徴点抽出（AKAZE）、位置と回転の補正（Homography）、画像のクロップ処理、OCR処理がそれぞれ完全に独立したクラスに分かれています。各クラスを単独でテスト可能です。
3. **GUIツール完備**  
   Tkinterを用いた直感的なUIが用意されており、読み取る領域（マスク）の自動スキャンや手動での微調整が視覚的に行えます。

## 🛠 導入方法 (Getting Started)

### 前提条件
* Python 3.8 以上がインストールされていること。
* (任意) 推論を高速化するためには NVIDIA GPU と CUDA ツールキットの導入を推奨します。

### 1. リポジトリのクローン
```bash
git clone https://github.com/Satoshi-CHO/smart-form-reader.git
cd smart-form-reader
```

### 2. 環境構築
付属のバッチファイルまたはシェルスクリプトを実行すると、自動で仮想環境 (`venv`) の作成と、必要なライブラリ(`torch`, `easyocr`, `opencv-python` 等) のインストールが行われます。

* **Windows の場合:**
  ```cmd
  run_app.bat
  ```
* **macOS / Linux の場合:**
  ```bash
  chmod +x run_app.sh
  ./run_app.sh
  ```

※初回起動時はモデルをダウンロードするため、時間がかかることがあります。

## 🚀 利用方法 (Usage)

環境構築後、`run_app.bat` (または `run_app.sh`) を再度実行すると、自動的にGUIアプリケーションが起動します。

### 基本的なワークフロー
1. **パスの設定**
   * **Input Dir**: 読み取りたい帳票画像が入っているフォルダ（デフォルト: `./input`）
   * **Output Dir**: 処理結果と切り出し画像が出力されるフォルダ（デフォルト: `./output`）
   * **Template Image**: 基準となるフォーマットの画像（デフォルト: `./template/template.png`）
   * **Masks Directory**: 読み取り領域の座標データと画像が保存されるフォルダ（デフォルト: `./masks`）

2. **マスクの準備と設定（既存のサンプルを利用可能）**
   * リポジトリにはサンプルのテンプレート画像とマスク設定が残っています。
   * 「Scan Masks Directory」をクリックすると、`masks/` フォルダ内の画像から自動で矩形領域を計算し、テーブルに追加します。
   * リスト内の行を選択し、「Edit Region」を押すことで視覚的に読み取り領域を微調整できます。
   * 各領域に対して「数字のみ(digits)」か「テキスト(text)」か、また「文字数のチェック（桁数）」を行うかを設定できます。

3. **処理の実行**
   * 設定が完了したら「Start Processing」をクリックします。
   * 指定した `input` フォルダ内のすべての画像に対して、テンプレート画像との**位置合わせ**（回転補正含む）、**領域の切り出し**、**OCR読み取り**が自動で実行されます。
   * 実行結果は `output/results.json` および中間ファイルとして保存されます。

## 🏗️ 開発者向け: エンジンの追加方法

新しいOCRエンジンを追加したい場合は、以下のステップで実装できます。

1. `src/ocr_engine.py` を開きます。
2. `IOcrStrategy` クラスを継承した新しいクラス（例: `NextGenOcrStrategy`）を作成し、`read(self, image: np.ndarray, expected_length: int)` メソッドを実装します。
3. `OcrEngineFactory` クラスのファクトリメソッドに、新しく作成したクラスを返す分岐を追加します。
4. これだけでバックエンドの切り替えにスムーズに対応できます。

## 📝 構成

```text
smart-form-reader/
├── src/                        # コアロジック
│   ├── image_processing.py     # 位置合わせ・クロップ層
│   └── ocr_engine.py           # OCR戦略・ファクトリ層
├── tests/                      # テストコード
├── docs/                       # ドキュメント等
├── main_gui.py                 # Tkinter GUI メインプログラム
├── setup_env.py                # 環境自動構築スクリプト
├── run_app.bat / .sh           # 起動用スクリプト
├── template/                   # 基準となるテンプレート画像（サンプル同梱）
├── masks/                      # 抽出領域のデータと画像（サンプル同梱）
├── input/                      # 処理対象の画像配置場所
└── output/                     # 処理結果の出力先
```
