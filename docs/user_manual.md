# OCRアプリケーション ユーザーマニュアル (User Manual)

## 1. 概要
本ツールは、スキャンした帳票画像から「数値」および「文字列」を抽出し、自動でデータ化するOCRアプリケーションです。
煩雑なコマンドライン操作（CLI）は不要で、アイコンをダブルクリックするだけで起動・操作が完結します。

## 2. 初回起動手順（セットアップ）
お使いのOSに合わせて、以下のスクリプトをダブルクリック（またはターミナルから実行）してください。

- **Windows:** `run_app.bat`
- **macOS:** `run_app.command`
- **Linux:** `run_app.sh`

初回起動時は、裏側でAIモデル（PyTorch, PaddleOCRなど）のダウンロードとインストールが自動で行われます。環境によっては10分以上かかる場合があります。ターミナル画面が閉じず、最終的にGUI設定画面が表示されるまでお待ちください。
※途中で停止してしまった場合やネットワークエラーが起きた場合は、再度スクリプトを実行することで途中からインストールが再開されます。

## 3. 基本的な使い方

1. **パス設定 (Settings)**
   - **Input Directory:** 読み取りたいスキャン画像が保存されているフォルダを指定します。
   - **Output Directory:** 抽出結果（JSONデータや中間画像）を保存するフォルダディレクトリを指定します。
   - **Template Image:** 位置合わせの基準となる「テンプレート（雛形）画像」を指定します。位置合わせはこの画像をベースに行われます。

2. **マスク設定 (Mask Settings)**
   抽出したい領域（ROI）の座標や設定を追加・編集します。
   ※自動スキャン機能（Scan Masks Directory）を使用する場合、用意するマスク画像は「**黒地に白（背景が黒、読み取りたい領域が白）**」で作成してください。OpenCVの仕様に適合し、最も正確に領域を検出できます。
   - **ID:** 出力時のキー名
   - **Type:** `digits`（数値専用・EasyOCR） または `text`（文字列・PaddleOCR）
   - **X, Y, W, H:** 抽出する領域の左上座標(X, Y)と、幅(W)・高さ(H)
   - **Length:** 期待される桁数（例: 7桁の場合は `7`。制限なしの場合は `0` または省略）

3. **処理開始 (Start Processing)**
   右下の「Start Processing / 処理開始」ボタンをクリックすると、OCR処理が開始されます。
   進行状況は随時「実行ログ」エリアに表示されます。
   ※上下逆さまにスキャンされた画像は、内部で自動的に180度回転補正されます。

## 4. 出力データについて
処理が完了すると、`Output Directory` に指定したフォルダ内に `results.json` が生成されます。また `intermediate` フォルダには切り出された各領域の小画像が保存され、OCRの結果が正しいか後から目視で確認することができます。
桁数などが一致しない場合は `error_flags` に警告内容（`DIGIT_MISMATCH` など）が記録されます。
