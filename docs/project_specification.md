# OCRアプリケーション プロジェクト構成ドキュメント

## 1. 要件定義書 (Requirements Definition)

### 1.1 目的
大量（約250枚〜）のスキャン済み帳票画像から、手書きの「7桁ID（数字）」および「日本語回答（文章）」を自動抽出し、データ化する。CLI操作を一切排除し、**「ダブルクリックで起動し、GUIで完結する」** ユーザー体験を提供する。

### 1.2 機能要件
* **ワンクリック起動:** Windows/Mac/Linux各環境で、スクリプト実行により仮想環境の自動起動を行う。
* **環境自動構築:** 初回起動時または環境破損時に、GPU/CPUを自動判別して必要なライブラリを再インストールする。
* **画像自動補正:** スキャン時の「上下逆さま（180度回転）」を自動検出し補正する。
* **動的領域切り出し:** マスク画像に基づき、ID（数字）や質問（文章）を個別に抽出する。（※マスク画像は画像解析の精度向上のため「黒地に白（黒背景・白抽出領域）」の仕様とする）
* **ハイブリッドOCR:** 
    * 数値：桁数固定バリデーション付エンジン（EasyOCR）。
    * 文章：手書き日本語に強いエンジン（PaddleOCR）。
* **GUI操作:** 
    * フォルダパス指定、マスク属性設定（数字/日本語、固定桁数チェック）を画面上で行う。
* **レポート出力:** 
    * 中間工程での切り出し失敗リスト、最終工程でのOCRエラー（桁数不一致等）をJSONおよびテキストで出力。

## 2. 仕様書 (Technical Specifications)

### 2.1 起動仕様 (One-Click Startup)
各OSにおいて、以下の挙動を保証する起動スクリプトを同梱する。

| OS | スクリプト名 | 挙動内容 |
| :--- | :--- | :--- |
| **Windows** | `run_app.bat` | 仮想環境（venv）の有無を確認。なければ`setup.bat`を実行後、`main_gui.py`を起動。 |
| **macOS** | `run_app.command` | ターミナルを自動起動し、実行権限を確認後、仮想環境経由で`main_gui.py`を起動。 |
| **Linux** | `run_app.sh` | シェル経由で仮想環境をアクティベートし、`main_gui.py`を起動。 |

### 2.2 ディレクトリ構造
```text
Project_Root/
├── run_app.bat (Windows起動用)
├── run_app.command (Mac起動用)
├── run_app.sh (Linux起動用)
├── setup_env.py (ハードウェア自動判別インストーラー)
├── main_gui.py (GUIメインプログラム)
├── masks/ (マスク領域設定 config.json)
├── template/ (位置合わせ用テンプレート画像)
├── input/ (スキャン画像)
└── output/ (最終結果 results.json + エラーレポート ocr_report.json)
    └── intermediate/ (切り出し画像 + 切り出しエラー crop_report.json)
```

### 2.3 エラー・バリデーション仕様
* **位置合わせ失敗:** マッチングスコア低減時に`CROP_FAILED`として記録し、中間画像を生成しない。
* **数値桁数チェック:** 指定桁数（例: 7桁）と一致しない場合、`DIGIT_MISMATCH`フラグを立て、読み取った生データを保持しつつ警告レポートに出力。
